# SolidityOasis

Runs a Solidity-based smart contract testing framework with test case management and code coverage analysis features.

The key benefits of using SolidityOasis include:

- Runs a Solidity-based smart contract
- testing framework with test case
- management and code coverage analysis

## Key Features

- Runs a Solidity-based smart contract
- testing framework with test case
- management and code coverage analysis

## Technology Stack

- typescript
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/SolidityOasis.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

SolidityOasis is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
